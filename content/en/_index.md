Welcome to the online documentation for Bruker EPR instrumentation. This site provides manuals, guides, and reference material for the following products:

<ul>
  <li><strong>Probes and Accessories</strong> — Setup and operating guides for the QLP-1.6 and QLP-2.5 Q-Band EPR probe heads, designed for pulsed EPR experiments requiring strong microwave pulses and large excitation bandwidths. Includes instructions for unpacking, connecting, sample insertion, tuning, maintenance, and specifications.</li>
  <li><strong>Resources</strong> — Reference material including waveguide band tables, conversion tables, and standard sample information.</li>
</ul>

To navigate, use the menu on the left or the top navigation bar. If you have questions or suggestions, contact the EPR applications team at <a href="mailto:epr-applications@bruker.com">epr-applications@bruker.com</a>.
