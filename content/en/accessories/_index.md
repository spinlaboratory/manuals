This section covers accessories for Bruker EPR spectrometers and probes. Please read the documentation for each accessory carefully before use.

- **Active Electric Shims (AES)** — A 5-channel active shim system for electromagnets with horizontal field orientation, commonly used in EPR spectroscopy. Covers installation and specifications.
- **Goniometer** — A motorized rotation accessory for EPR probes that allows remote-controlled sample rotation. Covers hardware assembly and software control via the pyB12SMC Python package.
- **Probe Mounting Bracket** — A support bracket for securing EPR probes inside liquid cryogen-free cryostats to dampen vibrations from the cold head.

If you have questions or need assistance with an accessory, contact epr-applications@bruker.com.
