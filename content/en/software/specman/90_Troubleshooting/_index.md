This section provides guidance for diagnosing and resolving common issues with the EPR spectrometer system. Topics are organized by subsystem.

- **SpecMan4EPR** — Software installation issues, re-licensing on new hardware, and debugging serial communication with the LabJack interface.
- **EPR Bridge** — Troubleshooting issues with the EPR bridge hardware.
- **Magnet** — Recovering the superconducting magnet after a quench.

{{% pageinfo color="primary" %}}
### Note
If you cannot resolve an issue using this guide, contact the EPR applications team at epr-applications@bruker.com. Please include the system serial number and a description of the problem, including any error messages shown by the software.
