This section covers the software used to operate and control Bruker EPR spectrometers.

- **SpecMan4EPR** — The primary spectrometer control and data acquisition software. Covers an overview of the software, installation, device configuration, magnet control, and troubleshooting.
- **DNPLab** — An open-source Python package for processing DNP and EPR data.
- **pyB12Logger** — A Python-based data logging utility for monitoring spectrometer parameters.

For detailed technical documentation of SpecMan4EPR beyond what is covered here, refer to the [official SpecMan4EPR website](https://specman4epr.com/manual/index.html).
